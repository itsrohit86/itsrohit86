# 🍕 Domino's Pizza SQL Analytics

> **Portfolio project | SQL Business Analysis | In Progress**

## 🎯 Project Snapshot

A practical pizza-sales analytics project built around business questions rather than isolated SQL exercises.

The current SQL file covers **25 scoped questions**, with **24 query implementations and 1 placeholder**. The companion industry-level question bank extends the roadmap to **40 business questions**.

**Business Question → SQL Query → Result → Business Insight → Business Recommendation**

## 🔎 What This Project Demonstrates

| Area | Coverage |
|---|---|
| Business & Sales | Revenue, orders, customers, AOV, monthly/day/hour analysis |
| Product Analytics | Best sellers, revenue ranking, category and size analysis |
| Customer Analytics | Top customers, frequency, RFM-style segmentation |
| Time Series | MoM growth, cumulative revenue, rolling 7-day revenue |
| Advanced SQL | CTEs, subqueries, DENSE_RANK, LAG, NTILE |
| BI Thinking | KPI design, retention, customer lifetime, concentration analysis |
